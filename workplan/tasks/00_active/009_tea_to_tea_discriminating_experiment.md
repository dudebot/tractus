# Task 009 — TEA-to-TEA discriminating experiment

> **Blocker:** Task 007 (frication retest) results landed. **Read first:**
> `docs/assumptions_audit.md` (Finding 2 — kinematic supervision claim
> UNDETERMINED), `docs/week1/fixed_rerun_hypotheses.md` (sets up the
> "this run cannot answer the structural-supervision question; only
> THIS task can" framing).

## Why this exists

The Week-1 closure verdict — "kinematic supervision is structurally
required" — justifies the entire Weeks 2-4 SPARC roadmap (~3 weeks
of work). After audit, that verdict is rated UNDETERMINED:

- The supporting Week-1 evidence had A1 (octave shift), A2 (non-
  converged), and A3 (frication off) confounders. All three confounders
  fixed in Tasks 006/007.
- Even with those fixed, the real-audio rerun (Task 007) cannot cleanly
  answer the structural question. Real audio has out-of-model elements
  (microphone, room, ElevenLabs vocoder character, MP3 roundtrip) that
  TEA cannot reproduce regardless of articulation. A failure to recover
  on real audio is consistent with both "TEA has expressive limits" and
  "kinematic supervision is required" — not discriminative.

The clean test is **TEA-to-TEA**: synthesize a target audio from a
KNOWN ground-truth articulation through TEA, then invert from acoustic
loss only and measure how well we recover the known articulation. If
acoustic-only inversion can recover known TEA articulators in-model
after convergence, the "structurally required" claim is falsified or
narrowed. If it cannot, SPARC has a much stronger justification.

This is Codex's recommended experiment from thread `[session identifier omitted]`.

## Goal

Establish empirically whether acoustic-only inverse-fitting can
recover known articulation in-model. Concrete, falsifiable answer
to the load-bearing roadmap claim.

## Inputs

- TEA simulator (already in repo, A1-fixed)
- copyfit script (already in repo, A1+frication wired)
- A small set of synthetic targets generated by hand-tuned dynamic
  area-function trajectories (built as part of this task)

## Deliverable

`scripts/tea_to_tea_discriminating.py` — a script that:

1. Generates **N synthetic targets** (recommended: N=2 for v0):
   - Target T1 — vowel-heavy: a smoothly-varying area function over
     ~2 s that traces out the canonical /a/ /i/ /u/ vowel triangle
     with continuous transitions. No fricatives. Frication off.
   - Target T2 — consonant-heavy: a sequence with at least 3
     fricative-bearing constriction events (tight constriction at
     section 35-45 sustained for 50-100ms each), plus voiced
     transitions. Frication on.
2. For each target, render through TEA at 44.1 kHz native, save as
   ground-truth WAV + ground-truth area-function NPZ.
3. Run copyfit inversion with **3 random seeds** per target (controls
   for optimization local minima). Use the same recipe as Task 007
   but with `--seeds 3 --iters 300` (fewer real-audio confounders →
   fewer iters needed, but more seeds for statistical robustness).
4. Measure both:
   - **Acoustic recovery:** final acoustic loss, multi-resolution STFT
     match between recon and target, formant correlation per vowel,
     Whisper transcription
   - **Articulatory recovery:** per-section, per-frame log-area MAE
     between recovered and ground-truth area function; constriction
     location + timing recall (within 50ms tolerance for fricative
     events); area trajectory correlation per section
5. Output a comparison report at `outputs/tea_to_tea/report.json`
   plus per-target spectrograms + area-function plots.

## Implementation notes

### Generating the synthetic targets

For T1 (vowel-heavy):
- Pick three vowel area functions from `tractus_controller/outputs/fixtures/story_1996_anchors.npz` (/a/, /i/, /u/).
- Time-interpolate linearly between them with cosine smoothing
  windows; total duration 2.4s (matches Natasha length so the inverse
  problem has the same n_frames=120).
- Use the standard glottis trajectory (extract_source equivalent on
  a synthetic F0 contour: 120 Hz steady, no jitter).
- Frication OFF.

For T2 (consonant-heavy):
- Hand-construct an area-function sequence: vowel /a/ → tight
  constriction at section 40 (alveolar) for 80 ms → vowel /i/ →
  tight constriction at section 35 (post-alveolar) for 80 ms →
  vowel /u/ → tight constriction at section 30 (velar) for 80 ms.
- Glottis: voiced for vowel windows, unvoiced (low pressure) for
  constriction windows.
- Frication ON.

Save ground-truth area function and ground-truth glottis trajectory
to NPZ so the recovery comparison has access.

### Inversion runs

Use copyfit script with these flags:
```
--audio outputs/tea_to_tea/T1_target.wav
--transcript "<dummy — pyworld DIO doesn't need a transcript>"
--out outputs/tea_to_tea/T1_recovery_seed{0,1,2}/
--iters 300
--seeds 1
--seed-base {0,1,2}
```
(Three separate seed runs rather than `--seeds 3` to keep run-level
artifacts clean.)

Frication ON for T2's recovery to match its target. Frication OFF
for T1.

### Articulatory recovery metric

For each (section, frame) cell:
- log-area MAE between recovered and ground-truth
- per-section: max constriction error (was the tightest constriction
  recovered to within 0.1 cm² of target?)
- per-frame: position-of-tightest-constriction recall (within 5
  sections of target?)

The point is: even if acoustic loss is low, the articulator
recovery may be wrong. Or vice versa. The two-axis measurement is
the diagnostic.

### Compute budget

Targets: ~5 min each to render + write fixtures.
Inversion runs: 6 total (2 targets × 3 seeds), ~5h each at the
post-A1-fix rate. Total ~30 GPU-hours serial. Could run 2 in
parallel if VRAM permits (test with one pair first; the per-iter
single-batch run uses ~5-7 GB based on Week-1 numbers, so two should
fit on the 16 GB card).

## Acceptance gates

### Gate 1 — Targets render cleanly

T1 and T2 WAVs play back without artifacts. Whisper transcription
of T1 produces vowel-leaning content (not necessarily words — these
are synthetic). T2 produces some consonantal noise. Ground-truth
NPZs have correct shapes and sensible value ranges.

### Gate 2 — Inversion runs complete

All 6 runs finish without OOM or NaN. Loss curves all show monotone
descent (modulo Adam noise). No silent failures.

### Gate 3 — Articulatory-recovery measurement

Per-target, across the 3 seeds:
- median log-area MAE
- median tightest-constriction position error (sections)
- median tightest-constriction area error (cm²)

Reported in the comparison JSON.

### Gate 4 — Verdict on the structural claim

Combine Gate-3 numbers into the verdict:

- **PROVEN ACOUSTIC SUFFICIENCY:** Across both targets, all 3 seeds:
  median log-area MAE < 0.3, position error < 5 sections, max-area
  error < 0.2 cm². → A4's "kinematic supervision is structurally
  required" claim is **falsified**. SPARC roadmap is optional.
- **WEAK ACOUSTIC RECOVERY:** Mixed results — vowel-target recovers
  but consonant-target doesn't. → A4's claim is **narrowed**: SPARC
  is required for fricatives but not for vowels. Pipeline complexity
  decision: still need SPARC labels for fricative-bearing utterances.
- **FAILED ACOUSTIC RECOVERY:** Both targets, all seeds: median
  log-area MAE > 0.6, position error > 10 sections, multiple seeds
  converge to clearly-wrong articulations. → A4's claim is
  **strengthened**. SPARC integration proceeds with confidence.

## Anti-deliverables

- **Don't use real-audio targets** here. The whole point is to
  control out-of-model confounders.
- **Don't use SPARC labels** to seed initialization or as a side
  loss — that defeats the experiment.
- **Don't tune to make the recovery look good.** Use the same
  recipe as Task 007. The point is a clean comparison, not a best-
  case demo.
- **Don't add more targets than needed.** N=2 is enough for the
  v0 verdict; N=10+ is research overkill.
- **Don't run before Task 007 results land.** Their hypotheses doc
  may flag a wiring bug that would invalidate this run too.
